As a Software Engineer at Myver, I am responsible for the design, provisioning, and ongoing operation of the company's AWS cloud infrastructure across development, staging, and production environments.

Key areas of ownership:

- **Cloud infrastructure platform**: design and maintenance of a multi-environment AWS platform built on ~44 reusable Terraform modules, covering networking (VPC, subnets, security groups), container orchestration (ECS Fargate), load balancing, API gateways, service discovery (AWS CloudMap), and data stores (RDS, DynamoDB, S3, ElastiCache). Blue-green deployments via AWS CodeDeploy ensure zero-downtime releases across all services.
- **Release management platform**: built a serverless deployment orchestration system (API Gateway, Lambda, DynamoDB) with a React/React Router dashboard that connects GitHub pull requests to production deployments, including approval workflows and migration-gated releases.
- **CI/CD**: designed and maintains shared GitHub Actions workflows used across all backend services, covering container image builds, ECR publishing, release registration, and automated stage deployments.
- **Identity platform**: migrated authentication from Auth0 to a self-hosted Ory Hydra (OAuth2/OIDC) + Ory Kratos (identity management) stack running on ECS Fargate.
- **Observability**: set up telemetry, log routing (FluentBit sidecars), and uptime monitoring with Betterstack.
